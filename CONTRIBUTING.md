# Contributing

Create a focused branch, inspect `git diff`, and keep commits small. Never commit credentials, real assessment evidence, `.data/`, `.study-progress.json`, or learner workspace output.

Curriculum changes must cite an approved official source, remain original summaries, include a safe lab boundary, and pass all curriculum tests. Interface changes must preserve semantic headings, labels, visible focus, reduced-motion behavior, responsive layouts, and keyboard navigation.

Before submitting a change, run type checking, lint, Vitest, the production build, Playwright, and the Python compatibility suite documented in `docs/TESTING.md`.
