# Lesson path compatibility

Lesson identity is the stable `week-NN-day-NN` identifier. Week 1–3 folders
were given descriptive slugs so a cloned repository exposes the subject. The
old paths are intentionally not duplicated; use this mapping when updating
bookmarks or external links. Generated navigation always uses the new paths.

See each week README and `curriculum-manifest.json` for the current path.
