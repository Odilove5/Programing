# Week 02 — Make Decisions with Data

**Theme:** Existing Foundations / Bridge  
**Track:** Python  
**Content readiness:** Authored

## What you will learn

Preserve the completed foundation in Boolean logic, conditions, validation, functions, tests, and Git.

By the end of this week, you should be able to:

- Explain comparisons and Boolean logic
- Implement conditional branches and normalization and validation
- Diagnose failures involving functions and basic tests
- Build a scope decision tool
