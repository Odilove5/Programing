# Week 03 — Finish Loops and Bridge to Marketing

**Theme:** Existing Foundations / Bridge  
**Track:** Python  
**Content readiness:** Authored (partial)

## What you will learn

Complete the active loop lesson, then prove foundational fluency with campaign records from a blank file.

By the end of this week, you should be able to:

- Explain lists, sets, for loops, range, and while
- Implement state changes and termination and loop boundary tests
- Diagnose failures involving semantic Git diff review
- Build a blank-file campaign rules checker
