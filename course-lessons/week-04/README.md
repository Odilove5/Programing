# Week 04 — Transform Campaign Records

**Theme:** Python for Marketing Data  
**Track:** Python  
**Content readiness:** Draft

## What you will learn

Use nested collections and reusable functions to normalize realistic campaign data.

By the end of this week, you should be able to:

- Explain nested dictionaries
- Implement list comprehensions and pure transformations
- Diagnose failures involving malformed record evidence
- Build a campaign record transformer
