# Week 06 — Calculate Marketing KPIs

**Theme:** Python for Marketing Data  
**Track:** Python  
**Content readiness:** Draft

## What you will learn

Calculate CTR, CPC, CPA, and ROAS deterministically with safe zero handling.

By the end of this week, you should be able to:

- Explain ratio formulas
- Implement zero denominators and numeric validation
- Diagnose failures involving human-readable summaries
- Build a deterministic KPI calculator
