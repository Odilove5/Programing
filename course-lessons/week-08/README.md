# Week 08 — Model the Marketing Domain

**Theme:** Reliable Business Logic & Data Models  
**Track:** Python  
**Content readiness:** Draft

## What you will learn

Represent core marketing concepts with typed dataclasses and enums.

By the end of this week, you should be able to:

- Explain dataclasses
- Implement enums and type hints
- Diagnose failures involving model invariants
- Build Campaign and MetricSnapshot models
