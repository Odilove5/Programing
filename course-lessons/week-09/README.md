# Week 09 — Design Pure Business Rules

**Theme:** Reliable Business Logic & Data Models  
**Track:** Python  
**Content readiness:** Draft

## What you will learn

Separate deterministic calculations and decisions from I/O and presentation.

By the end of this week, you should be able to:

- Explain pure functions
- Implement separation of concerns and normalization
- Diagnose failures involving dependency ordering
- Build goal-progress rules
