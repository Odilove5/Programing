# Week 15 — Design Mock-First Connectors

**Theme:** APIs & Business Data Integration  
**Track:** Integrated project  
**Content readiness:** Draft

## What you will learn

Define injectable Analytics, CRM, and Ads interfaces with mock implementations.

By the end of this week, you should be able to:

- Explain protocols and interfaces
- Implement dependency injection and mock clients
- Diagnose failures involving contract tests
- Build Marketing Data API Connector
