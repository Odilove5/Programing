# Week 16 — Design Services and Repositories

**Theme:** Backend & Persistence  
**Track:** Python  
**Content readiness:** Draft

## What you will learn

Apply OOP where state and collaborators justify it, with explicit boundaries.

By the end of this week, you should be able to:

- Explain service responsibilities
- Implement repository interfaces and composition
- Diagnose failures involving error boundaries
- Build campaign and goal services
