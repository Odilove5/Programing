# Week 17 — Persist Marketing Data

**Theme:** Backend & Persistence  
**Track:** Python automation  
**Content readiness:** Draft

## What you will learn

Use SQLite and parameterized SQL for goals, metrics, actions, and evidence.

By the end of this week, you should be able to:

- Explain tables and relationships
- Implement CRUD and constraints
- Diagnose failures involving transactions
- Build a SQLite evidence repository
