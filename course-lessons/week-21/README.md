# Week 21 — Construct Grounded Context

**Theme:** LLM Engineering  
**Track:** AI engineering  
**Content readiness:** Draft

## What you will learn

Build prompts from verified goals, KPIs, and evidence while treating context as untrusted.

By the end of this week, you should be able to:

- Explain context selection
- Implement prompt construction and evidence references
- Diagnose failures involving prompt injection boundaries
- Build an analyst context builder

- Complete module 20
