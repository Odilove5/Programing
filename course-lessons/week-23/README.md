# Week 23 — Evaluate the AI Analyst

**Theme:** LLM Engineering  
**Track:** Integrated project  
**Content readiness:** Draft

## What you will learn

Measure recommendation quality, grounding, cost, and refusal behavior with fixtures.

By the end of this week, you should be able to:

- Explain deterministic eval cases
- Implement grounding checks and uncertainty
- Diagnose failures involving token and cost budgets
- Build AI Performance Analyst
