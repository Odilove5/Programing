# Week 26 — Orchestrate Bounded State

**Theme:** Tools, Agents & Orchestration  
**Track:** Python automation  
**Content readiness:** Draft

## What you will learn

Use state machines, bounded loops, retries, idempotency, and recovery.

By the end of this week, you should be able to:

- Explain state transitions
- Implement persistent versus transient state and step limits
- Diagnose failures involving idempotency
- Build a resumable workflow
