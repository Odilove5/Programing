# Week 27 — Coordinate Specialized Agents

**Theme:** Tools, Agents & Orchestration  
**Track:** Integrated project  
**Content readiness:** Draft

## What you will learn

Introduce only roles with distinct contracts and evaluate their collaboration.

By the end of this week, you should be able to:

- Explain Strategist and Analyst roles
- Implement Research and Content roles and handoff schemas
- Diagnose failures involving agent evaluation
- Build Agent Workflow
