# Week 28 — Classify Actions with Policy

**Theme:** Policy Engine & Human Oversight  
**Track:** Python  
**Content readiness:** Draft

## What you will learn

Express deterministic allow, deny, and approval-required decisions as policy code.

By the end of this week, you should be able to:

- Explain action classes
- Implement policy rules and fail-closed defaults
- Diagnose failures involving decision evidence
- Build a policy evaluator
