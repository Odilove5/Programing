# Week 35 — Measure Outcomes and Replan

**Theme:** Autonomous MarketingOps Capstone  
**Track:** Capstone  
**Content readiness:** Draft

## What you will learn

Close the loop with delayed metrics, causal caution, scheduling, and bounded replanning.

By the end of this week, you should be able to:

- Explain outcome windows
- Implement before/after evidence and scheduler state
- Diagnose failures involving iteration budgets
- Build the measured optimization loop
