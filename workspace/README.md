# Workspace classification

This directory contains historical and starter material, not canonical course
progress. Do not infer completion from files here.

| Group | Classification |
|---|---|
| `week3-day2-campaign-collections/` | Public starter exercise and tests |
| `day5-authorization-project/` | Historical student/reference material; review before publishing elsewhere |
| `day6-target-data-normalizer/` | Historical student/reference material |
| `lab data/` | Local/example output; fictional only |

Recommended long-term separation is `exercises/`, `solutions/`, `examples/`,
and ignored `learner-workspace/`. Existing tracked material is preserved until
the owner approves a history-preserving archive or migration.
