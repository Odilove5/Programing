# Week 3 Day 2 — Campaign collections

This is a student workspace for choosing Python data structures while working
with fictional campaign records. It performs no network activity and contains
no credentials.

## Task

Implement `summarize_campaigns(campaigns)` in `exercise.py` so it:

- returns campaign names in input order;
- derives a set of unique channel values;
- returns only active campaign records;
- handles an empty list without crashing.

Before running it, predict the result for the provided records. Then add one
malformed-record case and decide whether to reject it, preserve evidence, or
handle it another safe way.

Run:

```bash
python exercise.py
```

The student writes the implementation. Do not replace the TODO with a copied
solution.
